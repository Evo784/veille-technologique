Journal de veille

Sources

Autorité : 5 = officiel/éditeur ; 4 = média technique ou expert identifié ; 3 = communauté utile non officielle ; 1-2 = difficile à vérifier.

KPIs / QMS

Valeurs de la dernière session. Un KPI sans donnée suffisante affiche « n/d » plutôt qu'une valeur inventée.

Score qualité d'une information = 30 % pertinence + 25 % crédibilité + 25 % nouveauté + 20 % efficacité (sur 5).

Méthode

  1. CollecterFlux RSS officiels (automatique) + sources manuelles (docs, roadmaps).
  2. VérifierSource identifiable, date, source primaire, cross-check, méfiance envers le contenu SEO.
  3. AnalyserNotes /5 (pertinence, crédibilité, nouveauté, efficacité, utilité), horizon, thème, signal faible.
  4. StockerUne session datée en JSON par quinzaine : l'historique n'est jamais supprimé.
  5. DiffuserCe site, publié sur GitHub Pages à chaque nouvelle session.
  6. AjusterSources et mots-clés corrigés selon les KPIs (section Analyse).

Critères de vérification

  • Fiabilité : autorité de la source notée /5 ; sources officielles prioritaires.
  • Cross-check : « oui » seulement si une 2e source est citée dans la fiche (champ « recoupé avec »).
  • Date : date de publication et date de collecte conservées ; « inconnue » si non vérifiable.
  • Fake news / hype : annonces marketing marquées comme telles ; Reddit et Hacker News jamais comme preuve unique.
  • Langues et synonymes : veille en anglais (langue des sources primaires) et en français ; mots-clés avec variantes (« agent », « agentic », « coding agent », « MCP »).

Biais identifiés

Écosystème Microsoft / GitHub

Une large part des sources sont des éditeurs du même groupe. Un recoupement entre deux blogs Microsoft n'est pas indépendant.

Sources anglophones

Quasiment 100 % d'anglais. Normal pour le développement, mais les usages et le marché francophones sont peu couverts.

Technologies médiatisées

Les agents IA dominent les annonces ; leur adoption réelle n'est pas mesurée par ces mêmes annonces.

Annonces marketing

Préversions et fonctionnalités expérimentales sont signalées comme telles ; elles ne valent pas adoption.

Outils déjà utilisés

La veille suit surtout ce que j'utilise (C#, Angular, GitHub). Des alternatives (autres langages, autres frameworks) peuvent être ignorées.

Notation automatique

Les sessions automatiques notent par mots-clés. Les scores sont à valider manuellement ; ils sont marqués « auto ».
